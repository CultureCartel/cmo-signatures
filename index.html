Step 1Check your details

These fill the text and links. Your name and title inside the banner animation are fixed.

Step 2Choose the motion

Every loop opens on the finished logo, so Outlook for Windows, which only shows frame one, still looks right.

Step 3Choose the layout and copy

Copy signature puts formatted HTML on your clipboard. Copy HTML gives you the raw code for tools that want it.

Step 4Install it

Gmail

  1. Settings, See all settings, General, Signature.
  2. Create new and paste.
  3. Scroll down and Save Changes.

Outlook web and new Outlook

  1. Settings, Account, Signatures.
  2. New signature, paste, save.
  3. Set it as the default for new mail and replies.

Apple Mail

  1. Mail, Settings, Signatures, plus.
  2. Untick “Always match my default message font”.
  3. Paste. GIFs animate in Mail and iOS Mail.

Good to know

Use the Compact Reply layout for long threads. Outlook for Windows shows a still, finished logo. Everywhere else animates.
