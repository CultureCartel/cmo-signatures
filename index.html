Step 4 · Install it

Gmail

  1. Gear icon, See all settings.
  2. Scroll to Signature, Create new, paste.
  3. Scroll down and Save Changes.

Outlook

  1. Settings, Account, Signatures.
  2. New signature, paste, save.
  3. Set it as the default for new mail and replies.

Apple Mail

  1. Mail, Settings, Signatures, plus.
  2. Untick “Always match my default message font”.
  3. Paste. It animates in Mail and iOS Mail.

Good to know

Use Compact Reply for long threads. Outlook for Windows shows a still, finished logo. Everywhere else animates.
